# Arquivo — plano original (v1)

Estes documentos descrevem a **primeira versão** do plano: um app com login Google, áudio, revisão espaçada, lembretes por e-mail, inglês e espanhol, construído como um monolito modular com PostgreSQL, RabbitMQ e um worker.

Em 2026-10-04, o MVP foi reduzido a uma missão local (cafeteria, inglês C1, um único aluno, estado em memória). As decisões que mudaram estão nos ADRs 008 a 017 (veja o [índice](../adr/README.md)).

Eles ficam aqui como **visão de longo prazo** e como material de estudo (comparar as duas arquiteturas é útil), mas **não são a referência atual**. A referência atual é o [`docs/architecture.md`](../architecture.md).
